System Overview & Mission

LankaEase is a full-stack on-demand local services and provider marketplace platform designed specifically for Sri Lanka. It bridges the gap between households and verified technical professionals across 5 critical service verticals, incorporating real-time GPS dispatching, native tri-lingual localization, dynamic QR-code invoicing, and a dedicated Family Assistance mode for elderly and home companion support.

Core Workflow Pillars (As Shown in Architecture Reel)
📱 Stage 01
Customer Mobile App Request

Intuitive booking flows, instant service selection, and scheduling built with React 19, TypeScript, and PWA + downloadable Android APK packaging.

🛠️ Stage 02
5 Verified Service Providers

Dedicated vetted onboarding pipeline for Electricians, Plumbers, Cleaners, Mechanics, and Family Caretakers with identity verification and rating telemetry.

📍 Stage 03
Real-Time GPS Tracking

Live geolocation technician routing, interactive map dispatching, distance calculation, and arrival ETA countdowns for seamless coordination.

🌐 Stage 04
Multi-Language Support

Native tri-lingual localization across all client and provider touchpoints supporting English, Sinhala (සිංහල), and Tamil (தமிழ்).

💳 Stage 05
Instant Invoice & Payment

Dynamic digital bill generation with instant QR-code payment settlement, card processing, and automated downloadable invoices.

🤝 Stage 06
Family Assistance Mode

Specialized compassionate workflows supporting Elder Care, Companion Services, and Support for Household Tasks for busy families and diaspora.

Full-Stack Engineering & Cloud Infrastructure
⚡ Backend API

Java 21 Spring Boot 3.3.4 RESTful micro-architecture, containerized with Docker, deployed on Render with JWT security.

🗄️ Cloud Database

PostgreSQL on Supabase with Row Level Security (RLS), ACID relational transactions, and connection pooling.

💬 Real-Time Messaging

WebSocket / STOMP protocol for two-way live customer-provider direct chat, status push, and admin moderation.

📦 Client Distribution

React 19 + TypeScript on Netlify, full Progressive Web App (PWA) offline caching, and Android APK packaging.
